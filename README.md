# Simple Interest Calculator

A Bash-based calculator that computes simple interest using principal, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- Principal amount
- Annual rate of interest
- Time period in years

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
